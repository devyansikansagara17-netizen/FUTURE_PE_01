# FUTURE_PE_01 — LocalCopy AI

**Future Interns Prompt Engineering Task 1**

LocalCopy AI is an AI-powered website copy generator for local businesses. It helps users create structured homepage copy, service descriptions, call-to-action sections, and SEO content from business details.

## Live Website

https://pixelperfect-copywriter.lovable.app

## Project Objective

The objective is to demonstrate prompt engineering by transforming business information into clear, persuasive, and structured website content.

## Features

- AI-generated homepage content
- Business-specific service descriptions
- Contact, booking, and enquiry CTA content
- SEO page title, meta description, and keyword suggestions
- Business types including salons, cafes, clinics, digital agencies, and other local businesses
- Tone and CTA customization
- Copy, Copy All Content, and Regenerate controls
- Input validation and error handling

## How to Use

1. Open the live website.
2. Enter the business name, type, location, and services.
3. Add the target audience and USP if available.
4. Select the preferred tone and CTA.
5. Click Generate Website Copy.
6. Review the Homepage, Services, CTA, and SEO results.
7. Copy the content or regenerate a section.

## Prompt Engineering

The application uses structured instructions to combine business details with content requirements. The prompt design considers business type, location, audience, services, tone, and CTA.

The system should avoid unsupported prices, awards, qualifications, reviews, and other invented claims.

## Example Business

Darpan Beauty Parlour — Jamjodhpur, Gujarat.

This example demonstrates how the generator creates salon-specific content for bridal makeup, hair services, and skincare.
