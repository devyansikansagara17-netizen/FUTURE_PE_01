- SEO output
- About and Documentation section

## Generation Workflow

1. The user enters business information.
2. The application validates required fields.
3. The configured AI generation flow processes the brief.
4. Generated content is displayed in separate sections.
5. The user can copy or regenerate content.

## Error Handling

The application should show clear messages when required information is missing or AI generation fails.

## Security

Private API keys and credentials must not be committed to the public repository. Use secure server-side configuration or the platform's supported AI integration.
